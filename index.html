Questions, answered.

Do I need a product key?

Yes. Access to the builder is protected by a product key from You B Tech. Each key has a limit on how many apps it can build, and the remaining quota is visible inside the app.

Where are my apps built?

On GitHub Actions, in a private repository in your own GitHub account. Your project never touches a shared build server.

Is the source code available?

No. Only the finished downloads, this page and the product video are public. The source code stays private.

Which file should I pick on Android?

If you are unsure, take the universal APK. Newer phones usually run the ARM64 file, older phones the ARM32 file, and emulators the x86_64 file.

How do I run the Linux build?

Extract the .tar.gz anywhere, then run the ybt_builder file inside. It works on any 64-bit Linux distribution that has GTK 3 installed.

Windows says the app is from an unknown publisher.

The installer is not signed with a paid code-signing certificate yet, so Windows SmartScreen may ask for confirmation. Choose "More info" and then "Run anyway", and compare the file with the published SHA256SUMS.
